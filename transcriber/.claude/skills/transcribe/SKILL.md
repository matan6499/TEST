# תמלול סרטון

## שלב 1: תמלול גולמי
הרץ מתיקיית הפרויקט:

```
python transcribe.py "<לינק או נתיב לקובץ>"
```

- ברירת מחדל: זיהוי שפה אוטומטי. בעברית נטען המודל `ivrit-ai/whisper-large-v3-turbo-ct2` (מאומן במיוחד לעברית), בשאר השפות `large-v3-turbo`.
- אם המשתמש ציין שפה, הוסף `--language he` / `--language en`.
- סרטון ארוך: הרץ ברקע ועקוב אחרי הפלט.
- אם ההורדה נכשלה (סרטון פרטי, דורש התחברות): עדכן את yt-dlp עם `pip install -U yt-dlp` ונסה שוב פעם אחת. אם עדיין נכשל, בקש מהמשתמש לשלוח קובץ.

בסוף נוצרים `output/<שם>/raw.txt` ו-`raw_timestamps.txt`.

## שלב 2: סידור
קרא את `raw.txt` (ואת `raw_timestamps.txt` כדי לזהות הפסקות ומעברים) וכתוב `output/<שם>/transcript.md`:

```
# <כותרת הסרטון>
מקור: <לינק/קובץ> | אורך: <משך>

<פסקאות התמלול>
```

מה מותר:
- פיסוק (נקודות, פסיקים, סימני שאלה) ושבירה לפסקאות לפי רצף הדיבור.
- אם יש כמה דוברים ואפשר להבחין ביניהם מהתוכן: `**דובר 1:**`, `**דובר 2:**`.
- כותרות משנה (`##`) רק כשיש מעבר נושא ברור, בניסוח ניטרלי וקצר של הנושא, לא סיכום.
- רשימה ממוספרת רק כשהדובר עצמו מונה פריטים ("דבר ראשון... דבר שני...").

מה אסור:
- להוסיף מילים, הסברים, הקדמה או סיכום.
- להחליף מילים, לתקן דקדוק או סלנג, לקצר חזרות.
- מקף ארוך (—).
- מילה חשודה כשגיאת תמלול: משאירים כמו שהיא ומוסיפים `[?]`.

## שלב 3: מסירה
הצג למשתמש את התמלול המסודר בצ'אט (אם ארוך מאוד, את הנתיב לקובץ ואת ההתחלה), וציין כמה סימוני `[?]` יש.
