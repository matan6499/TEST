## ל-Claude Code: מה בונים ואיך

אתה מקים לבעלים עוזר WhatsApp חדש, **פרויקט נפרד לגמרי** מכל בוט אחר שכבר קיים במחשב.

הקוד המלא, בדוק ועובד, נמצא בתיקייה `bot/` שליד הקובץ הזה: 126 בדיקות עוברות. אל תוריד גרסה אחרת ואל תכתוב מאפס.

דבר עם הבעלים בעברית פשוטה, צעד אחד בכל פעם. הוא לא בהכרח טכני.

### שלב 0: שאלות לפני שמתחילים (אחת בכל פעם)

1. איך קוראים לעוזר? השם הזה נכנס ל-`agentName` ול-`wakeWords`.
2. בשביל מה העוזר ומי ידבר איתו: רק הבעלים, או גם קבוצות עם אנשים אחרים?
3. איזה אופי? מקצועי, חברי או מצחיק. מזה כותבים את `systemPromptAppend`.
4. איזה מספר יהיה הבוט, ומה המספר האישי של הבעלים (המספר שינהל אותו)?
5. האם יש כבר שרת? ראה את הסעיף "אם במחשב כבר רץ בוט אחר" למטה.

- `selfEdit`: הבעלים מבקש בוואטסאפ שינוי בקוד של הבוט. הבוט מריץ Claude Code על עותק נפרד ובודק, ומעדכן רק אחרי "כן". יש לו החזרה אוטומטית לגרסה הקודמת. דורש שהקוד בשרת יהיה ריפו גיט (נוצר לבד), sudo ללא סיסמה, ושירות בשם `whatsapp-bot`.

### שלב 2: התקנה מקומית וחיבור WhatsApp

1. מעתיקים את `bot/` לתיקייה חדשה עם שם משלה, למשל `~/<שם-העוזר>-bot`. **לא** לתוך `~/claude-whatsapp-bot` אם התיקייה הזו קיימת: שם כבר רץ בוט אחר.
   מריצים שם `npm install --ignore-scripts --no-fund --no-audit && npm test`.
2. **הבעלים** לוחץ פעמיים על `start.command` שבתיקייה. מנגנון ההגנה של Claude Code חוסם הפעלה של סוכן שאפשר לשלוט בו דרך WhatsApp. זה צפוי. אל תעקוף: תסביר לבעלים ותן לו ללחוץ.
   **אם כבר רץ בוט אחר במחשב, הפורטים 7654 ו-7655 תפוסים.** בדוק קודם עם `lsof -i :7654`. אם הם תפוסים, שנה את `BASE_PORT` ב-`lib/accounts.js` ל-7754 לפני ההפעלה. הדשבורדים יעברו ל-7754 ול-7755.
3. בדף `http://127.0.0.1:7654` יוצרים חשבון ונכנסים לדשבורד.
4. סורקים QR **מתוך WhatsApp Business של מספר הבוט**: הגדרות, מכשירים מקושרים, קישור מכשיר.
5. באשף בוחרים "מספר ייעודי לבוט" ומצמידים את המספר האישי של הבעלים: הוא שולח לבוט בפרטי קוד בן 6 ספרות.
6. **הרשאות: מצב צ'אט בוט מוגבל.** זה חובה אם הבוט בקבוצות עם אנשים אחרים. הקוד מריץ את המצב הזה בלי כלים (`--tools ''`, `--permission-mode default`). אל תחזיר את `plan`.
7. בהגדרות ממלאים: `ownerName`, `agentName` ו-`wakeWords`. בשדה ההנחיות כותבים את האופי ואת מה שהעוזר צריך לדעת.

### שלב 3: שרת חינמי (כדי שירוץ כשהמחשב כבוי)

**Oracle Cloud Always Free**: שרת ARM בחינם.

1. **הבעלים נרשם** ב-oracle.com/cloud/free. כרטיס אשראי נדרש רק לאימות. Region: Israel Central, ואם אין מקום אז Frankfurt.
2. יוצרים מפתח SSH: `ssh-keygen -t ed25519 -N "" -f ~/.ssh/<שם>_server`.
3. Create instance:
   - Ubuntu 24.04, Shape **VM.Standard.A1.Flex** עם 1 OCPU ו-6GB.
   - Create new VCN, ומדביקים את המפתח הציבורי.
   - **מלכודת:** המתג של Public IP נעול במסך היצירה. אחרי היצירה: Instance, Networking, ה-VNIC, IP administration, Edit, **Ephemeral public IP**, Update.
4. ב-`~/.ssh/config` מוסיפים Host חדש עם **שם ייחודי** (לא `wa-bot`, השם הזה כבר תפוס), עם `User ubuntu`, IdentityFile ו-`ServerAliveInterval 30`.
5. ההתקנה וההפעלה בשרת ייחסמו לך. הכן לבעלים קובץ `.command` בשולחן העבודה שעושה את הדברים האלה:
   - מתקין Node 22 (nodesource) ו-Claude Code: `curl -fsSL https://claude.ai/install.sh | bash`.
   - מריץ `sudo timedatectl set-timezone Asia/Jerusalem`.
   - מריץ `ssh -t <host> '~/.local/bin/claude'` כדי **שהבעלים יתחבר** (`/login`). המקש `c` להעתקת הקישור לא עובד דרך SSH, אז מעתיקים עם Cmd+לחיצה.
   - עוצר את הבוט המקומי, אורז את התיקייה **כולל `accounts/`** (בלי `node_modules`, לוגים ו-pid), ומעלה עם `scp`.
   - בשרת: `npm install --ignore-scripts`, ושירות systemd בשם `whatsapp-bot` עם `User=ubuntu`, `WorkingDirectory=/home/ubuntu/<תיקייה>`, `Environment=PATH=/home/ubuntu/.local/bin:/usr/bin:/bin`, `ExecStart=/usr/bin/node hub.js` ו-`Restart=always`.
   - **אם `selfEdit` דלוק**, התיקייה בשרת חייבת להיות `/home/ubuntu/claude-whatsapp-bot`, כי ה-guard מניח את הנתיב הזה. אחרת מעדכנים את `selfedit-guard.sh`.
   - **אסור שהבוט ירוץ גם במחשב וגם בשרת.** WhatsApp ינתק את שניהם.
6. אחרי המעבר מותר לך לעדכן קוד ולהריץ `sudo systemctl restart whatsapp-bot`, אחרי שהבעלים אישר.
7. מומלץ לעשות מהתיקייה בשרת ריפו גיט ולקשר אליה עותק מקומי: `git remote add server <host>:<תיקייה>`, ובשרת `receive.denyCurrentBranch updateInstead`. מעדכנים עם `git push`, ולפני כל עבודה מריצים `git pull`.

### שלב 4: תמלול מקומי בשרת

```bash
sudo apt-get install -y build-essential cmake ffmpeg git
git clone --depth 1 https://github.com/ggml-org/whisper.cpp ~/whisper.cpp
cd ~/whisper.cpp && cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j2 --target whisper-cli
mkdir -p ~/models && curl -L -o ~/models/ivrit-turbo.bin https://huggingface.co/ivrit-ai/whisper-large-v3-turbo-ggml/resolve/main/ggml-model.bin
```
אל תשתמש במודל q5: על ARM הוא איטי יותר.

### שלב 5: OpenAI (אופציונלי, אבל רוב היכולות הנוספות תלויות בו)

- **מנוי ChatGPT לא מספיק**: ה-API הוא מוצר נפרד. הבעלים מטעין 5$ ב-platform.openai.com.

### שלב 7: התראות וגיבוי

- `extras/watchdog.sh`: מעתיקים לשרת. בקובץ `.ntfy-topic` שמים נושא אקראי חדש, **לא של בוט אחר**, ומוסיפים cron כל 5 דקות. הבעלים מתקין את האפליקציה ntfy ונרשם לנושא.
- `extras/backup.sh`: גיבוי לילי למחשב עם LaunchAgent. משנים בו את שם ה-Host ואת תיקיית היעד, כדי שלא יתנגש בגיבוי קיים.

### אם במחשב כבר רץ בוט אחר

- **אל תיגע בו.** אל תשנה את `~/claude-whatsapp-bot` ואת השרת `wa-bot`, ואל תשתמש בפורטים 7654 ו-7655, בנושא ה-ntfy, ב-LaunchAgent של הגיבוי ובשם ה-Host של הבוט האחר.
- העוזר החדש מקבל שרת Oracle משלו, תיקייה משלו ושם Host משלו.
- אם הבעלים רוצה לחסוך שרת ולשים את שני הבוטים על אותו שרת: זה אפשרי כחשבון נוסף ב-hub. אבל כל הפעלה מחדש תפיל גם את הבוט השני, אז זה רק אחרי שהבעלים אישר במפורש.

### מה לא עובד, אל תבזבז עליו זמן

- **Google Apps Script** ליומן ולמייל: גוגל חוסמת ("This app is blocked"). אם רוצים יומן, עובדים עם `lib/gcal.js`, שמשתמש ב-Calendar API הרשמי עם OAuth Desktop client ו-refresh token ב-`config.googleCalendar`. הבעלים עושה בעצמו את מסכי ההסכמה של גוגל.
- **הקלטת שיחות WhatsApp באייפון:** אפל חוסמת את זה.
- **חיבור המספר האישי, גם "רק לקריאה":** מסוכן. לא עושים.

### בדיקת סיום (לפני שאומרים לבעלים שהכל עובד)
